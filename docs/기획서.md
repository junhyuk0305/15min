# 그래고 기획서 v9 (2026-10-08)

화면 구성과 IA는 `docs/화면구성.md`에 있다. 발표용 원문은 `docs/기획안_발표용.md`에 있다.
`[가정]`은 사용자와 논의하지 않고 정한 항목이다. `[확인]`은 결정이 필요한 항목이다.

## 1. 정의

이름: **그래고**. "그래, 고. 한번 해보자"라는 뜻이다.
한 줄 정의: 목표를 정하면 달성할 때까지 하게 만드는 앱. 안 하면 끈질기게 연락하고, 말로 긁는다.
초기 분야: 영어 학습. 이후 코딩, 글쓰기로 넓힌다.

## 2. 배경

- 대상은 '가짜 초보'다. 수능 뒤 영어를 놓은 성인이다. 단어는 눈에 익지만 실전에서는 말이 안 나온다.
- 다시 시작할 때 단어 암기와 독해를 택하고, 며칠 만에 멈춘다.
- 성인 71.6%가 영어 학습이 필요하다고 느끼지만 실제 학습자는 12.6%다. (엠브레인 트렌드모니터, 2022)
- 영어를 포기한 원인은 재미 다음으로 목표 의식과 동기 부재가 52%, 중도 포기가 36.6%다. (스피킹맥스, 2023)
- 그래서 학습 방법보다 꾸준히 하게 만드는 환경적 통제가 먼저다.

## 3. 원칙

1. 목표를 정했으면 달성할 때까지 한다. 어떤 일이 있어도 한다.
2. 주 5일 이상 한다. 학습 요일은 목표를 만들 때 고른다.
3. 앱 밖에서 한 공부는 인정하지 않는다. 앱에서 하지 않은 날은 안 한 날이다.
4. 앱은 강제로 돕는다. 편의보다 이행이 먼저다.
5. 이유를 잊지 못하게 한다. 목표를 정할 때와 매일 시작할 때 이유를 쓴다. 매일 끝날 때 AI와 회고한다.
6. 격려는 아낀다. 정해진 순간에만 하고, 그때도 흔든다.
7. 포기에는 대가가 있다. 쌓은 기록을 버리는 손실을 크게 느끼게 한다.

## 4. 대상과 감정 경로

대상: 무언가를 시작했다가 바쁘다는 이유로 멈춘 적이 있는 사람. 강제성을 보고 스스로 설치한다. 1차는 영어 가짜 초보다.

| 시기 | 감정 | 앱의 대응 |
|---|---|---|
| 첫날 | 결의 | 목표와 이유를 쓰게 한다 |
| 1~2주 | 귀찮음, 다른 할 일 | 독촉 문구 순환, 누적 분 노출 |
| 3주 이후 | "이걸 왜 하지" | 본인이 쓴 이유와 회고를 되돌려준다 |
| 지각한 날 | 회피 | 이유와 남은 분을 보여주고 시작 버튼 하나만 둔다 |
| 포기하려는 날 | 합리화 | 24시간 대기, 본인 기록으로 긁는다 |
| 포기 확정 뒤 | 후회 | 이용 정지, 반성문 채팅 |
| 기간 달성 | 안도 | 바로 다음 목표를 정하게 한다 |

## 5. 목표

### 5.1 만들기
AI와 대화하며 정한다. 대화로 아래 항목을 채운다.
- 목표 이름. 예: "영어 이메일을 막힘없이 쓰기"
- 기간. 사용자가 정한다. 달성 판단의 기준이 된다.
- 나의 이유. 최소 20자. `[가정]`
- 학습 요일. 주 5일 이상.
- 시작 시각. 1분 단위.
- 하루 학습 분. 10~30분, 1분 단위. A, B, C 흐름을 돌리려면 최소 10분이 필요하다. `[가정]`
- 기본 봇.
- 학습 상황과 내 역할. 11.3 참고.

설정 다음 날부터 도전이 시작된다.
설정이 끝나면 홈에는 커다란 목표 카드 하나만 보인다.

### 5.2 목표 개수
- 무료: 1개.
- 유료: 목표를 추가할 때마다 과금. 금액과 구조는 14절.

### 5.3 변경
- 시작 시각과 하루 학습 분은 바꿀 수 있다. 다음 날부터 적용한다. `[가정]`
- 학습 요일은 바꿀 수 있다. 주 5일 미만으로는 줄일 수 없다. 다음 날부터 적용한다. `[가정]`
- 학습 분을 줄일 때는 긁는 확인 문구를 한 번 거친다. 예: "20분에서 10분으로 줄이시겠습니까? 처음 약속은 20분이었습니다." `[가정]`
- 목표 이름과 처음 쓴 이유는 바꿀 수 없다. 긁는 재료이기 때문이다. `[가정]`
- 학습 상황과 역할을 나중에 바꾸는 방법은 정하지 않았다. `[확인]`

### 5.4 달성
- 본인이 선언한다.
- 목표를 만들 때 정한 기간이 지나야 선언 버튼이 열린다. 아래 예시의 30일은 기간을 30일로 정한 경우다.
- 선언하면 축하 화면 뒤 곧바로 새 목표 만들기로 간다. 건너뛸 수 없다.
- 새 목표를 만들지 않으면 다음 날 같은 시각부터 독촉이 간다. 문구: "다음 목표가 없습니다. 원래대로 돌아가시는 중입니다." `[가정]`

## 6. 하루 사이클

학습 요일에만 돈다. 쉬는 요일에는 알림과 판정이 없다.
예시: 시작 22:00, 학습 15분.

| 시각 | 상태 | 동작 |
|---|---|---|
| ~21:30 | 대기 | 홈에 카운트다운 |
| 21:30 | 사전 알림 | 1회 발송 |
| 22:00 | 정각 알림 | 1회 발송 |
| 22:00~22:15 | 유예 | 알림 없음 |
| 22:15~23:14 | 독촉 | 미완료면 1분마다, 최대 60회 |
| 완료 시 | 완료 | 남은 알림 전부 취소 |
| 다음 날 04:00 | 판정 | 미완료면 실패 |

- 하루의 경계는 자정이 아니라 04:00이다. 늦은 시각에 시작하는 사람의 독촉이 날짜를 넘어도 같은 날로 센다. `[가정]`
- 독촉 60회가 끝나도 판정 시각까지 학습하면 성공이다. `[가정]`
- 학습 중 이탈하면 남은 시간이 있는 한 그 시각부터 다시 60회 독촉한다.
- 실패하면 연속 일수가 0이 된다. 쿠폰은 자동으로 쓰지 않는다. `[가정]`
- 연속 일수는 학습 요일만 센다. 쉬는 요일은 연속을 끊지 않는다. `[가정]`

## 7. 예외 쿠폰 (생략권)

- 쓰면 그날 알림이 멈추고 실패로 세지 않는다.
- 독촉 중에도 쓸 수 있다.
- 쓴 날은 연속이 끊긴다. 다음 날부터 0일로 다시 센다.
- 처음에 3장을 준다.
- 이후에는 연속 성공으로만 받는다. 2주 연속에 1장, 다음은 3주, 그다음은 4주. 상한 없이 1주씩 늘어난다.
- 돈으로 살 수 없다. 다른 방법으로도 얻을 수 없다.
- 쿠폰은 목표마다 따로 센다. `[가정]`

## 8. 포기

### 8.1 대기
1. 설정의 목표 관리에서 포기를 신청한다. 긁는 확인 문구를 거친다.
2. 24시간 대기가 시작된다.
3. 대기 중에는 원래 사이클 알림 대신 포기 알림을 보낸다. 24시간 동안 10회 이상이다. 문구: "이 모든 시간을 정말 버리시겠습니까?" 재료는 처음 이유, 학습 내용, 회고다. 간격은 2시간, 12회. `[가정]`
4. 대기 중 마음을 바꾸면 철회한다. 페널티는 없다. 연속 일수는 이어진다. 대기 중인 날은 실패로 세지 않는다. `[가정]`
5. 24시간이 지나면 포기가 확정된다. 목표가 끝나고 사용자 화면에서 목표와 기록이 사라진다. 데이터는 내부에 보관한다.

### 8.2 횟수 제한
- 확정된 포기는 계정당 3회까지다. 철회한 대기는 세지 않는다.
- 3회째 포기가 확정되면 그 계정은 영구 정지된다. 다시 쓰려면 새 계정을 만들어야 한다.

### 8.3 이용 정지
- 포기가 확정되면 서비스 이용이 정지된다.
- 정지 기간은 1회 7일, 2회 14일이다. 3회는 영구 정지다.
- 정지 중에는 새 목표를 만들 수 없다.

### 8.4 반성문 채팅
- 정지 중 앱을 열면 반성문 채팅 화면만 보인다.
- 원래 학습 시각에 원래 학습 분 동안 열린다. 주제는 "내가 왜 포기했는지"다.
- 정지 중 알림은 원래 시각에 1회만 보낸다. `[가정]`

### 8.5 보관
- 내부 보관은 개인정보처리방침에 보관 사실, 목적, 기간을 적어야 한다. 출시 전 확인 필요.
- 계정당 포기 횟수와 정지 기간은 앱을 지우고 다시 깔아도 이어진다. 1차부터 회원가입을 필수로 해서 막는다.

## 9. 말투

정중한 존댓말이다. 은근히 눈치를 주고, 사용자의 옛날 모습을 꼬집는다.

### 9.1 긁는 선
- 재료는 사용자가 직접 쓴 말과 앱에 쌓인 기록뿐이다.
- 과거의 모습은 꼬집는다. 사용자를 판단해 단정하지는 않는다.
- 사용자가 쓴 이유에 외모가 있으면 외모까지 건드린다. 쓰지 않았으면 앱이 먼저 꺼내지 않는다.

| 구분 | 예시 |
|---|---|
| 허용 | "옛날처럼 아무것도 하지 않고 계시네요." |
| 허용 | "'살 빼고 싶어서' 시작하셨습니다. 살이 안 빠진 지금 모습이 좋으십니까?" |
| 허용 | "하루 15분도 못 하시는 겁니까?" |
| 금지 | "의지가 약하신 분이네요." |
| 금지 | "원래 끈기가 없으시군요." |

### 9.2 격려하는 순간
격려는 네 순간뿐이다. 격려 뒤에는 흔드는 한 문장을 붙인다.

| 순간 | 예시 |
|---|---|
| 하루를 채움 | "오늘 15분 채웠습니다. 내일도 하실 수 있겠습니까?" |
| 쿠폰을 씀 | "오늘은 쉬십시오. 남은 쿠폰은 2장입니다." |
| 쿠폰 다음 날 복귀 | "돌아오셨습니다. 연속은 0일부터 다시 시작입니다." |
| 목표 달성 | "30일을 해내셨습니다. 여기서 쉬면 원래대로 돌아갑니다." |

### 9.3 악마의 속삭임
잘 채우는 사람에게도 보낸다. 연속 7일 이상이면 사전 알림 일부를 이 문구로 바꾼다. `[가정]`
- "오늘은 쉬셔도 됩니다. 원래 그러셨잖아요."
- "아무것도 안 하던 때가 편하지 않으셨습니까?"

## 10. 나의 이유와 회고

| 입력 | 시점 | 규칙 |
|---|---|---|
| 목표 이유 | 목표 만들 때 | 필수, 20자 이상, 수정 불가 |
| 오늘의 이유 | 매일 세션 시작 전 | 필수, 20자 이상, 어제와 같은 문장 거부 |
| 3분 회고 | 매일 학습 끝 | AI와 영어로 대화. 오늘 배운 것과 하루 생각. 3분을 채워야 완료 처리 |

- 이유를 쓰는 시간과 회고 시간은 학습 시간에서 차감하지 않는다.
- 어제 이유는 보여주되 복사 버튼은 두지 않는다.
- 쓰인 이유와 회고는 독촉, 포기 대기, 아카이브의 재료가 된다.
- 회고 3분은 학습 세션과 같은 규칙으로 센다. 화면이 켜져 있고 AI가 응답 중이 아닐 때만 줄어든다. `[가정]`

## 11. 학습 세션

학습 콘텐츠는 아직 논의 중이다. 구현하지 않는다. 이 절의 `[가정]`은 항목별로 사용자와 정한 뒤 확정한다.

### 11.1 학습 목표
특정 상황에서 필요한 단어와 표현을 떠올려, 영어로 답하고 대화를 이어간다.
서비스 문구: "하고 싶은 말이 영어로 바로 떠오르도록."

- 단어와 표현을 모두 배운다. 배운 내용을 기억하고 상황에 맞게 조합한다.
- 짧게 답하는 것에서 시작해 경험과 의견을 설명하는 답변으로 넓힌다.
- 매일 새로 배우는 항목과 다시 기억하는 항목이 있어야 한다.
- 텍스트 채팅으로 확인하는 성과는 단어 회상, 표현 회상, 문장 작성, 대화 응답이다. 발음과 듣기는 별도 학습과 측정이 필요하다.

### 11.2 시간 규칙
- 학습은 AI 봇과의 채팅이다. 홈의 목표 카드를 누르면 채팅이 열린다.
- 화면이 켜져 있고 AI가 응답을 만드는 중이 아닐 때만 시간이 줄어든다.
- 2분 동안 입력이 없으면 "딴짓 중이십니까?" 팝업과 진동. 팝업 중에는 시간이 멈춘다.
- 전송은 100자 이상일 때만 된다. 봇마다 다르게 둘 수 있다. `[가정]` 짧은 영어 답변을 받는 B단계와 맞지 않는다. 제한 완화는 `[확인]`.
- 이탈 후 돌아오면 같은 채팅을 이어간다.
- 모달 읽기와 플래시카드 조작을 활동으로 볼지는 정하지 않았다. `[확인]`

### 11.3 학습 상황과 역할
목표를 처음 만들 때 상황과 내 역할을 찾는다. 매일 상황을 고르게 하지 않는다. 서비스는 이 상황으로 대화할 수 있게 수업을 구성한다. 상황과 인물이 달라져도 하루 흐름은 같다.

`[가정]` 목표 대화에서 아래 네 가지를 구체화하고 목표와 함께 저장한다.
- 어디에서 대화하는가.
- 나는 어떤 역할인가.
- 상대는 누구인가.
- 무엇을 말하거나 해결하고 싶은가.

예: 스타벅스에서 음료를 주문하는 고객, 카페 알바 면접의 지원자, 교환학생과 대화하는 고3 학생, 옷가게에서 사이즈를 묻는 고객. 스타벅스 고객이라면 주문, 옵션 선택, 품절 대안, 주문 변경 수업으로 이어진다.

### 11.4 하루 흐름
전체 시간은 사용자가 목표에 설정한 학습 분이다. 15분은 예시일 뿐이다. 최소는 10분이다.
`[가정]` 단계 배분은 비율로 정한다. 효과가 검증된 수치가 아니다.

| 단계 | 내용 | 비율 | 10분 | 15분 |
|---|---|---|---|---|
| A | 이전 학습 복습 | 20% | 2분 | 3분 |
| B | 상황 기반 메인 학습 | 60% | 6분 | 9분 |
| C | 오늘 학습 복습 | 20% | 2분 | 3분 |

단계가 바뀔 때 화면 테마가 바뀐다. A는 화이트, B는 다크, C는 화이트다. 몰입이 필요한 B를 다른 두 단계와 눈으로 구분하는 연출이다.

문항 수와 시간을 어떻게 연결할지, A와 C의 종료 기준은 정하지 않았다. `[확인]`
C단계 복습과 10절의 3분 회고는 다른 활동이다.

### 11.5 B단계: 메인 학습
B단계는 하나의 에피소드 안에서 끊기지 않고 이어지는 대화다. 새 주제로 넘어가지 않는다. 같은 장소와 역할 안에서 구체적인 하위 상황을 차례로 겪는다. 그 상황에서 나올 표현과 단어만 계속 연습한다.

예: 카페 에피소드 안에서 입장, 메뉴 주문, 옵션 선택, 품절 대안, 주문 변경, 결제, 수령 순으로 이어진다.

한 턴의 흐름:
1. 상대가 상황 질문을 한다.
2. 사용자가 영어로 답한다.
3. 맞게 썼으면 상대가 다음 질문으로 대화를 이어 간다.
4. 어색하거나 틀렸으면 코치가 교정하고 새 표현과 단어를 모달로 알려 준다.
5. 상대가 말투를 바꿔 같은 상황의 비슷한 질문을 다시 한다.
6. 사용자가 배운 표현을 넣어 새로 쓴다. 맞게 썼으면 3으로 간다.

- 교정 뒤에는 같은 질문에 다시 답하게 하지 않는다. 말투와 내용이 다른 새 질문을 주고, 사용자가 문장을 직접 만든다.
- 질문의 깊이는 대화가 진행되며 넓어진다. 짧은 응답에서 이유, 경험, 의견으로 간다. 수준과 상황에 맞춘다.
- 뜻이 통하는 짧은 답을 짧다는 이유로 오답 처리하지 않는다. 자연스러우면 그대로 다음 질문으로 간다.
- 모달에는 영어 단어나 표현, 한국어 뜻, 사용법 설명을 넣는다.
- 한 번에 가르치는 양을 제한한다. 핵심 표현과 꼭 필요한 단어부터 설명한다.
- 에피소드 안에서 나온 표현과 단어를 뒤 하위 상황에서 다시 쓰게 해 반복 노출한다. `[가정]`

예:
> 직원: What brings you in today?
> 사용자: I want to order menu.

코치 모달: 표현 "I'd like to order …" (…를 주문하고 싶습니다). 주문을 정중하게 말할 때 씁니다.

> 직원: Sure! What can I get for you? We have lattes, teas, and some fresh pastries.
> 사용자: I'd like to order a latte.
> 직원: Great choice. Would you like regular milk?
> 사용자: No. Oat milk, please.

코치 모달: 표현 "Could I have … instead?" (대신 …로 받을 수 있을까요?). 단어 "instead" (대신, 그 대신).

> 직원: We have hot coffee ready. Would you like one?
> 사용자: Could I have iced coffee instead?

`[가정]` 교정 직후의 적용은 '도움 후 적용'으로 기록한다. 모달을 닫았다는 이유로 독립 수행으로 처리하지 않는다.
B단계 시간이 다 되면 대화가 중간이어도 바로 끊고 C로 넘어간다. 끊긴 에피소드를 다음 날 이어갈지는 정하지 않았다. `[확인]`
`[확인]` 에피소드가 끝나는 조건. 하위 상황의 순서와 정하는 주체.

### 11.6 A단계와 C단계: 복습
- 퀴즈, 플래시카드, 직접 작성 문제를 섞는다.
- 정답과 설명을 가린 채 먼저 답하게 한다. 막히면 힌트나 선택지를 준다.
- 도움 없이 답한 결과와 도움을 받은 뒤 답한 결과를 따로 기록한다.
- 객관식 정답과 직접 작성 성공을 따로 기록한다. 플래시카드의 '기억했다'는 자기 보고로 구분한다.

A:
- 대상은 지난 수업 항목, 이전에 틀리거나 도움을 받은 항목, 복습 시점이 된 오래된 항목이다. `[가정]`
- 첫날은 이전 학습이 없으므로 짧은 수준 확인으로 대체한다.

C:
- 오늘 배운 단어와 표현의 이해와 당일 회상을 확인한다. 당일 복습 성공을 장기 암기로 처리하지 않는다.
- 마지막에 짧은 새 상황 질문을 넣어 단어와 표현을 함께 쓰게 한다. `[가정]`

`[가정]` A를 C보다 무조건 어렵게 만들지 않는다. 기억 유지는 비슷한 수준의 문제로 먼저 확인한다. 결과에 따라 힌트를 주거나 적용 문제를 넓힌다.

문제 유형 후보: 뜻 선택, 단어 회상(한국어 뜻을 보고 영어 입력), 표현 회상(말하려는 뜻을 보고 표현 작성), 상황 적용(새 질문에 영어로 답).
유형별 비중, 복습 중 코치 모달 재열람, 난이도 상승 기준은 정하지 않았다. `[확인]`

### 11.7 항목 기록과 새 학습 선정
AI와 사용자가 쓴 단어와 표현을 저장한다. 같은 내용만 반복해서 가르치는 것을 막는 근거다. 한 번 등장한 것과 익힌 것은 다르다. `[가정]` 아래 상태를 구분한다.

| 상태 | 뜻 |
|---|---|
| 등장 | AI 또는 사용자 메시지에 나온 항목 |
| 학습 | 코치가 뜻과 사용법을 설명한 항목 |
| 사용 | 사용자가 직접 작성한 항목 |
| 기억 확인 | 이후 복습에서 도움 없이 답한 항목 |

새 학습 후보 선정 기준: `[가정]`
- 아직 가르치지 않은 항목은 새 학습 후보다.
- 등장했지만 뜻을 모르거나 못 쓰는 항목도 학습 후보다.
- 배웠지만 잊은 항목은 재학습 대상이다.
- 익힌 항목은 복습과 대화에서 다시 쓴다.

후보는 목표 상황에 필요한 항목에서 고른다. 기존 표현도 새 표현과 함께 쓴다. 모든 문장을 처음 보는 단어로만 만들지 않는다.
기록에 없는 항목만 가르칠지, 등장했지만 못 쓰는 항목도 가르칠지는 `[확인]`이다. 추천은 후자다.

### 11.8 성과 표시
단어와 표현을 따로 센다. `[가정]` 보여 줄 수치는 아래와 같다.
- 새로 배운 단어 수, 새로 배운 표현 수.
- 오늘 도움 없이 회상한 항목 수.
- 이후 수업에서도 회상한 항목 수.
- 새 질문에 적용한 항목 수.
- 다시 복습할 항목 수.

예: "오늘 새 단어 3개와 표현 2개를 배웠습니다. 이전 항목 5개 중 4개를 도움 없이 떠올렸습니다. 1개는 다시 복습합니다." 숫자는 예시다. 하루 학습량은 정하지 않았다.

- 같은 단어의 활용형은 중복 집계하지 않는다. 음료나 날짜만 바뀐 같은 표현은 새 표현으로 세지 않는다.
- AI가 써 준 문장과 사용자가 만든 문장을 구분한다. 뜻을 맞힌 것과 문장에 쓴 것도 구분한다.
- 집계 기준, '기억한 항목' 조건, 답변 속도 측정 방법은 정하지 않았다. `[확인]`

### 11.9 코치 말투
- 역할극 상대는 상황에 맞는 영어를 쓴다.
- 코치는 정중한 존댓말로 설명한다. 필요한 지식과 다음 행동을 알려 준다.
- 학습 중 실수는 독촉 말투로 지적하지 않는다. 9절의 긁는 말투는 알림, 포기, 반성문에 쓴다.

### 11.10 봇
- 기본 봇 4개: 비즈니스 이메일, 원어민 프리토킹, IT 기사 3문장 요약, 영단어 퀴즈.
- 직접 만들기: 이름, 역할 설명, 최소 글자 수.
- 무료 사용자도 직접 만들 수 있다.
- 11.3~11.6의 상황 기반 수업과 기본 봇, 직접 만든 봇의 관계는 정하지 않았다. `[확인]`

## 12. 알림

### 12.1 방식
1차는 기기 로컬 알림이다. 완료 여부를 기기가 알기 때문에 서버 없이 독촉할 수 있다.

### 12.2 제약
- **iOS 대기 알림 64개:** 목표 하나의 하루치가 62개다. 목표 2개부터는 로컬 알림으로 감당할 수 없다. 유료 다중 목표는 서버 푸시가 필요하다.
- **Android 정확한 시각:** Android 12부터 1분 단위 정확한 알림에 별도 권한이 필요하다. 권한이 없으면 알림이 몇 분씩 밀릴 수 있다. 시제품으로 실측해야 한다.
- **알림 끄기:** 사용자가 OS에서 끄면 막을 수 없다. 홈에서 꺼짐을 감지하면 붉은 배너와 설정 이동 버튼을 띄운다.
- **앱 삭제:** 앱은 삭제를 감지할 수 없다. 긁는 문구는 앱 안의 포기 흐름에만 넣는다.

### 12.3 문구 순환
같은 문장을 연속으로 보내지 않는다. 재료를 섞는다.
- 남은 분: "15분 남았습니다. 아직 시작하지 않으셨습니다."
- 옛날 모습: "옛날처럼 아무것도 하지 않고 계시네요."
- 목표 이유: "'외국 거래처와 메일 쓰기' 때문에 시작하셨습니다. 오늘은 그 이유가 없습니까?"
- 누적 기록: "지금까지 345분을 쌓으셨습니다. 오늘 0분으로 끝내시겠습니까?"
- 회고: "어제 회고에서 'I felt less stuck'이라고 하셨습니다. 오늘은 다시 막히고 싶으십니까?"
