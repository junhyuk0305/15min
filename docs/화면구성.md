# 그래고 화면 구성과 IA v1 (2026-10-07)

정책은 `docs/기획서.md`가 정본이다. 이 문서는 화면과 이동만 다룬다.

## 1. 디자인 원칙

- 글자와 숫자만 쓴다. 마스코트와 일러스트는 없다.
- 바탕은 아이보리, 글자는 검정, 경고색은 빨강 하나.
- 빨강은 독촉 상태와 포기 흐름에만 쓴다. 평소 화면에 쓰지 않는다. 예외: 입력 검증(조건을 못 채운 이유, 모자란 글자 수 카운터, 잘못된 입력)은 작은 빨강 글자로 보인다(UX 고도화 결정로그 3.1 "빨강 안내").
- 화면마다 가장 큰 요소는 숫자다. 누적 분, 남은 시간, 연속 일수.
- 화면마다 주 버튼은 하나다.

## 2. IA

```
그래고
├─ 온보딩 (첫 실행만)
│   ├─ O1 후킹
│   ├─ O2 문제 제기
│   ├─ O3 약속
│   ├─ O4 목표와 이유
│   ├─ O5 시각과 학습 분
│   ├─ O6 학습 방식
│   └─ O7 경고와 알림 권한
│
├─ 탭: 홈
│   ├─ H 홈 (상태 8가지)
│   ├─ 세션 흐름
│   │   ├─ S1 오늘의 이유
│   │   ├─ S2 채팅
│   │   ├─ S3 오늘의 소감
│   │   └─ S4 완료
│   ├─ C 쿠폰 시트
│   └─ 달성 흐름
│       ├─ A1 달성 선언 확인
│       ├─ A2 달성
│       └─ A3 새 목표 (O4, O5 재사용)
│
├─ 탭: 봇
│   ├─ B1 봇 목록
│   └─ B2 봇 만들기와 수정
│
├─ 탭: 기록
│   ├─ R1 달력과 카드 목록
│   └─ R2 카드 상세
│
└─ 탭: 설정
    ├─ T1 설정
    ├─ T2 목표 관리
    ├─ 포기 흐름
    │   ├─ G1 포기 확인
    │   ├─ G2 포기 대기 (홈 상태로도 표시)
    │   └─ G3 삭제 경고 (4번째 포기)
    └─ T3 알림 권한 안내
```

라우트:

| 라우트 | 화면 |
|---|---|
| /onboarding/[step] | O1~O7 |
| /(tabs)/index | H |
| /session/reason | S1 |
| /session/chat | S2 |
| /session/review | S3 |
| /session/done | S4 |
| /goal/achieve | A1, A2 |
| /goal/new | A3 |
| /(tabs)/bots, /bots/[id] | B1, B2 |
| /(tabs)/archive, /archive/[date] | R1, R2 |
| /(tabs)/settings, /settings/goal | T1, T2 |
| /settings/giveup | G1, G3 |

## 3. 핵심 흐름

### 3.1 첫 실행
1. O1~O3 스와이프.
2. O4에서 목표 이름과 이유 입력.
3. O5에서 시작 시각과 학습 분 선택.
4. O6 채팅 예시.
5. O7에서 동의하고 알림 권한 요청.
6. 홈으로 이동. 오늘 사이클 알림 예약.

### 3.2 하루 (22:00 시작, 15분)
1. 21:30 사전 알림.
2. 사용자가 알림이나 홈의 시작 버튼을 누른다.
3. S1 오늘의 이유를 쓴다.
4. S2 채팅. 15분이 줄어든다.
5. 0분이 되면 S3 소감을 쓴다.
6. S4 완료 화면. 알림 전부 취소.
7. 22:15까지 시작하지 않으면 1분마다 독촉. 알림을 누르면 S1로 간다.

### 3.3 중간 이탈
1. S2에서 앱을 나간다. 남은 시간 5분.
2. 나간 시각부터 1분마다 독촉 재시작.
3. 돌아오면 S2로 바로 들어간다. 이유는 다시 쓰지 않는다.

### 3.4 포기
1. T2에서 포기를 누른다.
2. G1에서 긁는 문구와 지금까지의 기록을 본다. 포기 신청 버튼을 누른다.
3. 홈이 포기 대기 상태가 된다. 남은 대기 시간과 철회 버튼.
4. 24시간 동안 기록으로 긁는 알림이 간다.
5. 철회하면 원래대로. 철회하지 않으면 목표 종료.
6. 4번째 신청이면 G1 대신 G3. 확인 즉시 삭제.

### 3.5 달성
1. 30일이 지나면 홈에 달성 선언 버튼이 생긴다.
2. A1 확인. A2 달성 화면.
3. A3 새 목표. 닫기 버튼 없음.

## 4. 홈 상태

홈은 하나의 화면이고 상태에 따라 중간 영역이 바뀐다.

| 상태 | 조건 | 중간 영역 | 주 버튼 | 색 |
|---|---|---|---|---|
| 대기 | 사전 알림 전 | 시작까지 카운트다운 | 없음 | 기본 |
| 임박 | 사전 알림 후 | 카운트다운, 오늘 할 분 | 지금 시작 | 기본 |
| 유예 | 시작~15분 | 경과 시간 | 지금 시작 | 기본 |
| 독촉 | 유예 이후 미완료 | 지난 분, 나의 이유 | 지금 시작 | 빨강 |
| 진행 중 이탈 | 남은 시간 있음 | 남은 분 | 이어서 하기 | 빨강 |
| 완료 | 오늘 채움 | 오늘 분, 소감 첫 줄 | 없음 | 기본 |
| 쿠폰 사용 | 오늘 쿠폰 | 남은 쿠폰, 다음 쿠폰 조건 | 없음 | 기본 |
| 포기 대기 | 포기 신청 후 | 남은 대기 시간, 처음 이유 | 포기 철회 | 빨강 |

독촉 상태의 빨강은 배경 전체를 쓴다. 깜빡임은 1회만 한다. `[가정]`

## 5. 화면별 구성

### 온보딩

| 화면 | 구성 | 주 버튼 |
|---|---|---|
| O1 후킹 | 큰 숫자 "하루 15분", 1년 5,475분, 3년 16,425분, 5년 27,375분 | 다음 |
| O2 문제 제기 | "그 15분, 매일 앉기 어려우셨죠?" | 다음 |
| O3 약속 | "해내실 때까지 물고 늘어지겠습니다." | 다음 |
| O4 목표와 이유 | 목표 이름 입력, 이유 입력, 글자 수 표시 | 다음. 20자 미만이면 비활성 |
| O5 시각과 분 | 시각 휠, 학습 분 휠 5~30, "매일, 쉬는 날 없음" 고정 문구 | 다음 |
| O6 학습 방식 | 채팅 예시 애니메이션, 100자 게이지 예시 | 다음 |
| O7 경고 | "약속한 시간에 오지 않으면 1분마다 연락합니다." 쿠폰 3장 안내 | 동의하고 알림 켜기 |

O7에서 알림 권한을 거부하면 다음으로 넘어가지 않는다. 설정 이동 버튼을 보여준다. `[가정]`

### 홈

| 영역 | 구성 |
|---|---|
| 위 | 목표 이름, 상태별 영역(4절). 화면에서 가장 큰 숫자 |
| 가운데 | 누적 분과 연속 일수 한 줄, 다음 마일스톤 게이지. 첫 학습 전에는 대신 첫 학습 순서 |
| 아래 | 오늘의 봇 가로 스와이프 |
| 보조 | 쿠폰 수 표시, 30일 이후 달성 선언 버튼, 알림 꺼짐 배너 |

### 세션

| 화면 | 구성 | 주 버튼 |
|---|---|---|
| S1 오늘의 이유 | 목표 이름, 어제 이유 읽기 전용, 입력창, 글자 수 | 시작. 20자 미만 또는 어제와 같으면 비활성 |
| S2 채팅 | 위 고정 남은 시간, 대화, 입력창, 글자 수 게이지 "86/100" | 전송. 100자 미만이면 비활성 |
| S2 딴짓 팝업 | "딴짓 중이십니까?", 진동 | 계속하기 |
| S3 오늘의 소감 | 오늘 쓴 글자 수, 입력창 | 완료. 20자 미만이면 비활성 |
| S4 완료 | 오늘 분, 누적 분, 연속 일수, 격려 한 문장과 흔드는 한 문장 | 확인 |

S2에서는 뒤로가기를 막지 않는다. 나가면 3.3 흐름을 탄다. `[가정]`

### 쿠폰 시트 C
- 남은 쿠폰 수, 다음 쿠폰까지 남은 연속 일수.
- "쓰면 연속이 0일로 돌아갑니다" 경고.
- 주 버튼: 쿠폰 쓰기.
- 진입: 홈의 쿠폰 표시. 독촉 상태에서도 열린다.

### 달성

| 화면 | 구성 | 주 버튼 |
|---|---|---|
| A1 확인 | 시작일, 경과 일수, 누적 분, 처음 이유 | 달성 선언 |
| A2 달성 | 대형 숫자로 일수와 분, 격려와 흔드는 문장 | 다음 목표 정하기 |
| A3 새 목표 | O4와 O5를 한 화면으로 | 시작. 닫기 없음 |

### 봇

| 화면 | 구성 | 주 버튼 |
|---|---|---|
| B1 목록 | 기본 봇 4개, 내 봇, 봇별 최소 글자 수 | 새 봇 |
| B2 만들기 | 이름, 역할 설명, 최소 글자 수 | 저장 |

### 기록

| 화면 | 구성 | 주 버튼 |
|---|---|---|
| R1 목록 | 달력: 완료, 실패, 쿠폰을 칸 색으로 표시. 아래 카드 목록 | 없음 |
| R2 상세 | 날짜, 분, 봇, 글자 수, 오늘의 이유, 채팅 전체, 소감 | 없음 |

### 설정

| 화면 | 구성 | 주 버튼 |
|---|---|---|
| T1 설정 | 목표 관리, 알림 권한 상태, 남은 쿠폰, 앱 정보 | 없음 |
| T2 목표 관리 | 목표 이름과 처음 이유 읽기 전용, 시각 변경, 분 변경, 포기 | 저장 |
| G1 포기 확인 | 처음 이유, 경과 일수, 누적 분, 긁는 문구, 남은 대기 횟수 | 포기 신청. 보조: 계속하기 |
| G3 삭제 경고 | "지금 포기하면 목표와 기록이 전부 삭제됩니다." | 삭제. 보조: 계속하기 |
| T3 알림 안내 | 알림이 꺼져 있다는 사실, 켜는 방법 | 설정 열기 |

G1과 G3에서는 계속하기 버튼을 더 크게 둔다. `[가정]`
