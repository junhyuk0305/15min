# 타임불독 기획서 v2 (2026-10-07)

원본 PRD를 구현 관점에서 다듬은 판이다. `[확인]` 표시는 사용자 답변이 필요한 항목이다.

## 1. 한 줄 정의

매일 정해진 시각에 5~30분, AI 코치와 영어로 대화하게 만드는 앱. 안 하면 1분마다 1시간 동안 알림을 보낸다.

## 2. 기술 스택 (squaretable과 동일 계열)

| 영역 | 선택 | 비고 |
|---|---|---|
| 앱 | Expo 57 · expo-router · TypeScript · zustand | iOS·Android 한 코드 |
| 알림 | expo-notifications **로컬 알림** | 서버 없이 독촉 가능 (아래 3절) |
| AI | Supabase Edge Function 뒤에 모델 격리 | 키를 앱에 두지 않음 `[확인 Q1·Q2]` |
| 저장 | 1차: AsyncStorage(기기) → 계정 도입 시 Supabase | `[확인 Q1]` |
| 빌드 | EAS build/submit | squaretable eas.json 재사용 |

## 3. 알림 설계 (핵심)

서버 푸시가 아니라 **기기 로컬 알림**으로 전부 처리한다. 이유: 독촉 여부는 "이 기기에서 목표 시간을 채웠나"로만 결정되므로 서버가 알 필요가 없다. 네트워크·서버 비용·푸시 토큰 관리가 사라진다.

예시: 22:00 시작, 목표 15분.

| 시각 | 동작 |
|---|---|
| 21:30 | 사전 리마인드 1회 |
| 22:00~22:15 | 유예. 알림 없음 |
| 22:15~23:14 | 미완료면 1분마다 60회 |
| 완료 시점 | 예약된 알림 전부 취소 |

구현 규칙
- 앱이 열릴 때마다 "오늘 사이클" 알림만 예약한다 (리마인드 1 + 독촉 60 = 61개). iOS는 대기 로컬 알림 64개 제한이 있어 여러 날을 미리 걸지 않는다.
- 재이탈: 학습 중 앱이 백그라운드로 가면 남은 시간이 0보다 클 때 **그 시각부터 60회**를 다시 예약한다. 다시 돌아오면 취소한다.
- Android는 전용 알림 채널(최대 중요도, 소리·진동)을 만든다. iOS는 `critical alert` 권한이 없으면 무음 모드를 못 뚫는다. 일반 알림으로 간다.
- 한계: 사용자가 OS에서 알림을 끄면 막을 수 없다. 온보딩 #6에서 권한을 받고, 홈에서 권한 꺼짐을 감지해 붉은 배너로 알린다.

## 4. 학습 세션 규칙

- 목표 시간 5~30분, 1분 단위.
- 요일 5~7개 선택. 4개 이하는 저장 버튼이 비활성화된다.
- 시간 차감: 화면이 켜져 있고 AI가 응답 생성 중이 아닐 때만 1초씩 줄어든다. `[확인 Q3]`
- 2분 무입력이면 "딴짓 중이신가요?" 팝업 + 진동. 팝업이 떠 있는 동안은 차감하지 않는다. `[확인 Q3]`
- 전송은 100자 이상일 때만 활성화. `[확인 Q4]`
- 세션 중 이탈 후 복귀하면 같은 채팅을 이어서 한다. 자정이 지나면 새 세션이다.
- 독촉 60회가 끝나도 그날 세션은 여전히 열려 있다. 자정까지 완료하면 성공으로 센다. `[확인 Q5]`

## 6. 데이터 모델 (기기 저장 기준)

- `settings`: startTime, targetMinutes, weekdays[], onboarded
- `bots[]`: id, name, systemPrompt, isBuiltin
- `sessions[]`: date, botId, activeSeconds, completed, messages[], userCharCount
- `stats`: totalMinutes (sessions에서 파생)

## 7. 범위 밖 (1차 출시 제외)

로그인, 결제, 웹 배포, 영어 외 분야, 소셜 기능.

## 8. 확인 질문

- **Q1 백엔드·계정.** AI 호출은 Supabase Edge Function을 두고 앱엔 키를 안 둔다. 계정과 로그인은 1차에 넣을지? 안 넣으면 기록은 기기에만 남고 기기 바꾸면 사라진다.
- **Q2 AI 모델과 비용.** squaretable처럼 Gemini를 쓸지. 매일 15분 대화면 1인당 월 비용이 생긴다. 무료로 풀지, 구독을 붙일지.
- **Q3 시간 차감.** "AI 응답 생성 중 멈춤 + 화면 켜져 있으면 차감"이 맞는지. 딴짓 팝업이 떠 있는 동안은 멈추는 게 맞는지.
- **Q4 최소 글자 수.** 100자가 전 봇 공통 고정인지, 봇마다 다르게 둘지. 영어 100자는 약 20단어다.
- **Q5 하루 실패 처리.** 독촉 1시간이 끝나고도 안 하면 그날은 실패인지, 자정까지 열어 두는지. 연속 일수(스트릭)를 보여줄지.
- **Q6 이름.** 타임불독으로 가는지. 번들 ID는 `com.dochackchack.timebulldog`으로 잡아 두었다.
