# 그래고 용어집

화면 문구는 이 파일을 따른다. 정본은 `docs/메가프롬프트_MVP출시.md` 7.6이다.
`npm run check:static`이 `src/lib/copy.ts`에서 "쓰지 않는 말"을 찾으면 실패한다. 법무 문서 원문(`copy.legal`)은 검사하지 않는다.

## 1. 낱말

| 쓰는 말 | 쓰지 않는 말 | 뜻 |
|---|---|---|
| 목표 | 미션, 챌린지 | 사용자가 정한 달성 대상 |
| 학습 | 세션, 수업, 공부 | 하루에 하는 A, B, C 전체 |
| 처음 이유 | 나의 이유, 목표 이유 | 목표를 만들 때 쓴 이유 |
| 오늘의 이유 | 오늘 이유, 시작 이유 | 매일 학습 전에 쓰는 이유 |
| 회고 | 소감, 리뷰 | 학습 끝의 3분 영어 대화 |
| 코치 | 봇, AI, 선생님 | 교정하고 설명하는 쪽 |
| 상대 | 직원, 캐릭터, 봇 | 역할극 속 인물. 화면에는 역할 이름을 쓴다 |
| 쿠폰 | 예외 쿠폰, 생략권, 휴식권 | 쓰면 그날 실패로 세지 않는 것 |
| 연속 N일 | 스트릭, 연속 일수 | 학습 요일 기준 연속 완료 |
| 학습 요일, 쉬는 요일 | 휴일, 오프 | |
| 포기 신청, 포기 철회, 포기 확정 | 그만두기, 취소 | |
| 이용 정지 | 차단, 정지 처분 | |
| 달성 선언 | 완료, 졸업 | |

"완료"는 하루 학습을 채운 상태(달력, 홈)에는 쓴다. 목표를 끝내는 뜻으로는 쓰지 않는다.
"취소"는 포기와 묶어 쓰지 않는다. 검사는 "포기 취소"만 잡는다.

## 2. 말투

1. 합니다체 하나다. 해요체(-요, -죠)는 쓰지 않는다.
2. 문장은 짧게 쓰고 한 문장에는 한 가지만 담는다. 대시(—)와 가운뎃점(·)으로 문장을 잇지 않는다.
3. "당신"은 쓰지 않는다. 주어를 빼거나 "지금까지"처럼 쓴다.
4. 긁는 말투는 알림, 홈의 독촉 상태, 포기 흐름, 반성문에만 쓴다. 학습 중 코치, 오류 안내, 설정 화면에서는 쓰지 않는다.
5. 오류 안내는 두 문장이다. 무엇이 안 됐는지, 무엇을 하면 되는지. 오류 코드와 영어 원문은 보이지 않는다.
6. 버튼은 동사로 끝나는 2~6자로 쓴다. 예: "지금 시작", "이어서 하기", "다시 보내기".
7. 숫자와 단위는 붙여 쓴다: 15분, 3장, 7일, 22:00. 천 단위에 쉼표를 찍는다.
