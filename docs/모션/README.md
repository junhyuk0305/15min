# 움직임 녹화 (UX 고도화 6.2)

웹 빌드(Expo 웹, 390×844, Asia/Seoul)에서 줄인 움직임을 끈 상태(`reduced_motion='no-preference'`)로 녹화했다. 2026-10-19, 브랜치 `feat/ux-polish`(HEAD 62c17b4 + 작업 중 변경).
처음 안내는 기기 저장소 씨앗(`graego-tips-v1`)으로 모두 본 것으로 두었다. 시간 이동은 `scripts/e2e/lib.py`의 make_user, make_goal, session_for와 scenarios.py S3·S7·S11 방식(SQL로 first_day, start_minutes, active_seconds 등을 옮김)을 따랐다. AI 함수는 `AI_FAKE=1`이다.
녹화 원본은 Playwright `record_video_dir`(25fps)이고, 흐름 시작 0.6초 전부터 끝까지 잘라 VP9로 다시 담았다. 소리는 없다.

전체 크기 1.04MB(10개). 같은 해시를 가진 파일은 없다.

### 결함 의심

1. **응답 도착 순간 대화가 위로 튐(05).** 입력 중 점이 사라지고 상대 답이 들어오는 프레임에서, "바리스타" 이름이 사라지고 대화 전체가 약 56px 위로 올라갔다가 다음 프레임(40ms 뒤)에 약 23px 내려온 자리에서 새 줄이 페이드로 들어온다. 재현: 학습 B에서 답을 보내고 응답을 기다리게 한 뒤 놓는다(`05` 흐름). 두 번 녹화해 두 번 모두 보였다. 의심 위치: `src/components/learn/Transcript.tsx`의 입력 중 줄(TypingLine) 제거와 새 줄 등장, 채팅 끝 스크롤(`ChatScroll`) 사이의 한 프레임.
2. **달성 선언 뒤 빈 화면 80ms(08).** 확인 화면 → 빈 아이보리 2프레임 → 축하 화면이 페이드 없이 나타난다. `src/app/goal/achieve.tsx`가 "선언할 목표가 없습니다."가 비치지 않게 일부러 빈 `Screen`을 그리는 구간이다. 깜빡임으로 보일 수 있다.
3. **상태가 바뀔 때 빈 프레임 1장(01 pop, 10 독촉 진입).** 이전 내용이 먼저 사라지고 새 내용이 0에서 페이드로 들어와 40ms 동안 빈 화면이 보인다. 갭분석 M15에 "크로스페이드는 하지 않았다"고 적힌 방식과 같은 원인으로 보인다. 크기가 작아 사람 눈에는 거의 띄지 않는다.
4. **카운트업 중 옆 숫자 밀림(07).** 완료 화면의 누적 숫자가 0분 → 20분으로 넓어지면서 오른쪽 "연속" 묶음이 약 20px 옆으로 밀려간다. 숫자 자리 폭이 고정돼 있지 않다.
5. 움직임과 별개로 본 것: 목표 관리 화면(390px 폭)에서 학습 요일 7칸이 한 줄에 다 들어가지 않아 "일"이 둘째 줄로 내려가고, 그 칸 아래쪽이 하단 버튼 영역에 가려진다(01 녹화 3초 프레임).

## 줄인 움직임 켬과 끔에서 끝까지 동작하는지

같은 스크립트를 녹화 없이 두 상태로 돌렸다. 두 상태 모두 콘솔 오류 0건.

| 흐름 | 확인한 것 | 끔(no-preference) | 켬(reduce) |
|---|---|---|---|
| 화면 전환 | 목표 관리 진입, 뒤로, 오늘의 이유 진입 | 통과 | 통과 |
| 쿠폰 시트 | 열기, 닫기, 다시 열어 쓰기, 결과 문구 | 통과 | 통과 |
| 학습 시트 | 나가기 시트 열고 계속하기, 길게 누르기 신고 시트 열고 닫기 | 통과 | 통과 |
| 단계 전환 | A → B, B → C가 시계 경계에서 넘어감 | 통과 | 통과 |
| 글자 표시 | 입력 중 표시(접근성 이름), 상대 답 전체가 보임 | 통과 | 통과 |
| 정답과 오답 | 오답 → 다시 답하기, 정답 안내 | 통과 | 통과 |
| 완료 | 회고 완료 → 완료 화면, 최종 숫자 | 통과 | 통과. 화면이 뜬 직후 0.15초에 이미 20분, 2일 |
| 달성 | 선언 → 축하 화면, 14일 | 통과 | 통과 |
| 포기 확정 | 끔: 떼면 신청 안 됨, 끝까지 누르면 신청(DB 기록). 켬: 2단계 진입 뒤 1초 안 탭은 신청 안 됨, 1.3초 뒤 탭으로 신청(DB 기록) | 통과 | 통과 |
| 독촉 진입 | 홈을 보는 중에 분 경계에서 독촉 상태로 바뀜 | 통과 | 통과 |

## 다시 찍는 법

스크립트는 저장소 밖(작업 스크래치패드)에 있다. Expo 웹 서버를 따로 띄우고 `E2E_APP_URL`을 그 주소로 둔다. 테스트 사용자 이메일 접두사는 `u9b-`다.

## 웹이 보여 주지 못하는 것

네이티브 화면 전환(오른쪽 push, 아래에서 올라오는 몰입 전환), 스와이프 뒤로, 햅틱(정답·오답, 포기 확정 heavy, 독촉 진입 warning, 완료 success), 시트 끌어 닫기 감각과 스프링, 키보드와 입력창이 함께 오르는 움직임, 시스템 시각 선택기, 기기 줄인 움직임 설정 연동은 웹 녹화로 확인할 수 없다. 실기기 확인은 HANDOFF 5.2.
