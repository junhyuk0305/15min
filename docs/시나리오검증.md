## 검증 방법

- 서버 로직: `supabase/tests/08_scenarios.test.sql`(pgTAP 53개). 2026-03-01(일)~03-28을 날짜 순서로 걷는다. 시각은 `app_private.*(…, p_now)`에 넣는다. 가입 트리거는 실제 `now()`를 보므로 S16만 `now()` 기준이다. `npm run test:db` 8파일 271개 통과.
- 알림: `src/lib/__tests__/plan.test.ts`에 S2, S7, S10 테스트 3개를 더했다. 원래 있던 테스트(쉬는 요일, first_day 전, 스냅샷)와 함께 통과한다. `npm test` 205개 통과.
- 화면: `scripts/e2e/scenarios.py`(Playwright, Chromium headless, 390×844, Asia/Seoul). 웹 개발 서버 8101, 로컬 Supabase, Edge Functions `AI_FAKE=1`.
  - S1, S16의 가입은 화면에서 이메일 OTP로 했다. 코드는 Mailpit에서 읽었다.
  - 나머지 사용자는 SQL로 만들었다. 세션은 GoTrue 비밀번호 로그인으로 받아 localStorage에 넣었다.
  - 시간 이동은 `first_day`, `start_minutes`, `days.session_started_at`, `active_seconds`, `retro_started_at`, `giveup_requested_at`, `suspended_until`을 과거로 옮겨서 했다.
- 결과 원본: `scripts/e2e/results.json`. 스크린샷: `docs/시나리오/`(40장, 1.3MB).
- 다시 돌리기: `npx expo start --web --port 8101` 뒤 `python scripts/e2e/scenarios.py [S1 …]`. S6은 실제로 2분 넘게 기다린다.

## 관찰 (결함 아님)

- S13: 정지가 풀리면 목표 정하기 화면으로 바로 가지 않는다. 홈의 "목표가 없습니다"와 주 버튼 "목표 정하기"를 거친다. 한 번 더 누르면 된다.
- S15: 웹 브라우저 뒤로 가기는 막지 못한다(결정로그 "달성 화면 숫자"). 웹에서는 홈으로 돌아갔다. Android 뒤로 가기와 iOS 제스처 차단은 실기기에서 봐야 한다.
- S6: 팝업이 뜨기 전 무입력 2분은 학습 시간으로 센다(300초 → 421초). 기획서 11.2는 "팝업 중에는 시간이 멈춘다"라 맞다.
- S4: 이탈은 웹 `visibilitychange`로 흉내 냈다. S5 강제 종료는 탭을 닫고 같은 저장소로 새 탭을 열어 흉내 냈다. 네이티브 AppState와 프로세스 종료는 실기기 확인이 남는다.
- S3: AI_FAKE의 B 대화는 교정이 없어 배운 항목이 생기지 않는다. 완료 화면에 "오늘은 새로 배운 항목이 없습니다."가 나온다. 고정 응답의 한계다.
- 검증용 사용자 `s1-ui@scenario.test`, `s2@scenario.test`~`s17@scenario.test`가 로컬 DB에 남아 있다. `s16@scenario.test`는 deleted_accounts 기록도 있다. 스크립트는 다시 돌릴 때 같은 이메일 사용자를 지우고 새로 만든다.
