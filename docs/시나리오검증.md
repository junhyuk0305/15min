## 결함

### 1. 학습 화면이 몇 초마다 요청을 다시 보내 딴짓 팝업이 뜨지 않는다 (높음, 회귀, `dc34451`에서 고침)

S6이 실패했다. 학습 B를 열어 두기만 해도 `lesson-turn`이 30초에 12번 불렸다. 학습 A도 `review-quiz`가 30초에 12번 불렸다. 요청이 끝날 때마다 `touch()`가 무입력 시간을 0으로 돌린다. 그래서 2분 무입력 팝업이 영원히 뜨지 않고, 아무것도 안 해도 학습 시간이 쌓인다.

복습(A, C)은 더 나쁘다. 다시 받을 때마다 `next()`가 입력한 답, 고른 보기, 채점 결과를 지운다. 답을 쓰는 중에 글자가 사라졌다("recei"를 친 직후 입력칸이 빈칸). 오답을 내면 "정답 보기"가 뜨기 전에 다음 문항으로 넘어갔다.

- 증거: `docs/시나리오/S6-딴짓.png`, 스크립트 출력(S6 세 항목 FAIL). 확인 스크립트는 세션 scratchpad의 `probe_reload.py`, `probe_wipe.py`다.
- 원인: `src/app/session/learn.tsx:39` `onGone={() => setGone(true)}`가 렌더마다 새 함수다. `Learn`은 `useNow(5000)`(30행)과 저장 때문에 몇 초마다 다시 그린다. `onGone`이 바뀌면 `save`(80행)와 `request`(115행)가 바뀐다. 그러면 `QuizPanel.tsx:73`의 `next`와 `LessonPanel.tsx:41`의 `load`가 바뀌고, 처음 한 번만 돌아야 할 effect(`QuizPanel.tsx:75`, `LessonPanel.tsx:43`)가 다시 돈다. `onGone`은 커밋 `aa87e44`(Q-E 04:00 경계)에서 들어왔다.
- 같은 모양: `src/app/session/retro.tsx:38`도 같다. `open`(retro.tsx 137행 effect)이 다시 돌며 `run`이 `setFailed(null)`, `setError(null)`, `touch()`를 한다. 회고에서도 딴짓 팝업이 뜨지 않고, 보내기 실패 문장이 몇 초 뒤 지워질 수 있다. 회고는 코드로만 확인했다.
- 고친 뒤 확인(`dc34451`, 웹 서버 `--clear` 재시작):
  - (a) C 상황 문항에 "Could I get the receipt"를 쓰고 10초 동안 1초마다 읽었다. 10번 모두 그대로였다.
  - (b) C 첫 오답 뒤 10초 동안 1초마다 셌다. "다시 답하기"와 "정답 보기"가 10번 모두 있었다(`docs/화면상태/learn-c-graded-5s.png`).
  - (c) B를 열고 7초 안에 `lesson-turn` 1번, 그 뒤 30초 동안 0번. A도 `review-quiz` 1번 뒤 30초 동안 0번.
  - (d) S6 통과. 딴짓 팝업이 뜨고 15초 동안 시계와 active_seconds가 멈췄다. `learn-idle.png`도 다시 찍었다.
  - S3, S4, S5도 다시 돌려 통과했다.
