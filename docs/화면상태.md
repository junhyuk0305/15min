# 그래고 화면 상태표

MP 7.4의 표다. 모든 라우트 × 로딩, 빈 데이터, 오류, 오프라인, 정상. 칸마다 보이는 것과 주 버튼을 적는다.
작성 2026-10-18. 기준 코드는 `src/app/`이다. 다른 작업자가 맡은 화면은 코드를 읽고 채웠다. 화면으로 띄워 보지 못한 칸은 "확인 필요"로 둔다.

## 0. 모든 화면 공통

| 상황 | 동작 |
|---|---|
| 앱 시작 | 세션 확인과 첫 읽기가 끝날 때까지 스플래시. 10초가 넘으면 캐시로 연다(`_layout` BOOT_TIMEOUT_MS) |
| 첫 읽기 실패, 캐시 없음 | 오류 화면 "앱을 열지 못했습니다" + 두 문장 안내. 주 버튼 "다시 시도" |
| 캐시 있음, 읽기 실패 | 캐시를 그대로 보이고 화면 위에 빨강 배너(`StatusBanner`). 네트워크면 "연결이 끊겨 마지막으로 받은 내용을 보여 줍니다.", 그 밖은 "최신 내용을 불러오지 못했습니다." 배너 안 글자 버튼 "다시 불러오기" |
| 렌더 오류 | 오류 화면 "화면을 그리지 못했습니다". 주 버튼 "다시 열기" |
| 서버 주소 없음 | 오류 화면 "앱 설정이 없습니다". 버튼 없음(개발 빌드 전용 상황) |
| 화면 안 요청 | 300ms가 넘으면 진행 표시, 10초가 넘으면 오류로 바꾼다(`selectors.loadPhaseOf`, `useLoadPhase`). 버튼 요청은 처리 중 비활성과 진행 표시(`useAction`) |
| 갈 곳 | `src/lib/route.ts` 한 곳이 정한다. 목표 없음, 정지, 영구 정지, 학습 중, 끝난 날 |

### 1.1 홈 상태별 가운데와 주 버튼

| 상태 | 가운데 | 주 버튼 | 바탕 |
|---|---|---|---|
| 목표 없음 | "목표가 없습니다" | 목표 정하기 | 아이보리 |
| 첫날 전 | "첫 학습까지" + 카운트다운 + "내일 HH:MM부터 N분 학습합니다." | 없음 | 아이보리 |
| 쉬는 요일 | "오늘은 쉬는 요일입니다" + 다음 학습일과 시각 | 없음 | 아이보리 |
| 대기 | "시작까지" + 카운트다운 + 시각과 분 | 없음 | 아이보리 |
| 임박 | 카운트다운 + "곧 시작입니다." | 지금 시작 | 아이보리 |
| 유예 | "N분 경과" + 독촉이 시작되는 시각 | 지금 시작 | 아이보리 |
| 독촉 | "N분 늦음" + 긁는 한 줄 + 처음 이유. 들어올 때 한 번 깜빡임 | 지금 시작 | 빨강 전체 |
| 진행 중 이탈 | "N분 남음"(회고 중이면 회고 남은 분) | 이어서 하기 | 빨강 전체 |
| 완료 | "N분 완료" + 오늘 회고 첫 답의 첫 줄 | 없음 | 아이보리 |
| 쿠폰 | "쿠폰 N장 남음" + 다음 쿠폰 조건 | 없음 | 아이보리 |
| 포기 대기 | 남은 대기 시간 + 처음 이유 | 포기 철회 | 빨강 전체 |

홈 위 빨강 배너는 이 순서로 쌓는다: 읽기 실패(오프라인), 알림 꺼짐(설정 열기), Android 정확한 알람 권한 없음(설정 열기). 정확한 알람 권한을 알 수 없으면(Expo Go, 웹) 띄우지 않는다.
지난 학습일 실패와 쿠폰 다음 날 복귀는 상단 숫자 아래 한 줄로 보인다.
