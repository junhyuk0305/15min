## 6. 연령 등급 질문지

App Store Connect의 연령 등급 질문에 아래처럼 답합니다. 가이드라인 2.3.6은 질문에 정직하게 답하라고 요구합니다.

| 자녀 보호 기능 | 없음 | 앱 안에 자녀 보호 기능이 없습니다 |
| 연령 확인 | 없음 | 가입 화면의 만 18세 이상 체크는 본인 확인이 아닌 자기 신고입니다 |

| 사용자 생성 콘텐츠 | 아니요 | 이용자가 쓴 글은 본인에게만 보입니다. 다른 이용자에게 공개하지 않습니다 |
| 소셜 미디어 | 아니요 | |

예상 등급은 4+입니다.

가입은 만 18세 이상만 받습니다. 질문지 결과보다 높은 등급을 고르는 선택지가 App Store Connect에 있으면 18+를 고릅니다. `[확인: 콘솔의 등급 선택 기능]`
한국 지역 등급(GRAC)은 게임과 엔터테인먼트 카테고리에만 붙습니다. 교육 카테고리는 해당하지 않습니다.

## 7. 수출 규정

`app.config.ts`의 iOS `infoPlist`에 `ITSAppUsesNonExemptEncryption: false`를 둡니다.
앱은 운영체제의 HTTPS만 씁니다. 자체 암호화를 넣지 않았으므로 면제 대상입니다.
이 값이 있으면 빌드를 올릴 때마다 수출 규정 질문이 나오지 않습니다.
